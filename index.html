Asignatura

Programación Web Fundamental

Clave del curso: INF-1024

Créditos 5 SATCA (3-2-5)
Horario Lun y Miér 10:00 - 12:00
Salón / Lab Laboratorio L2

Intención Didáctica

Esta asignatura aporta al perfil del egresado la capacidad de desarrollar e implementar aplicaciones web modernas, seguras y adaptables a distintos dispositivos. Se enfoca en el razonamiento lógico para la maquetación de interfaces, el uso de estándares actuales de la W3C y la integración de frameworks de maquetado ágil.

Competencias Previas

  • Lógica de programación y estructuras de datos básicas.
  • Manejo fundamental de sistemas operativos y redes.
  • Comprensión de lectura técnica en idioma inglés.

Competencias a Adquirir

  • Diseñar e implementar maquetación web responsiva de alta calidad.
  • Integrar frameworks de estilos como Bootstrap 5 para desarrollo ágil.
  • Consumir e integrar datos y APIs en el frontend.

Temario y Prácticas

Unidad 1: Arquitectura Web y HTML5 Semántico

Semanas 1 - 4

Protocolos HTTP/HTTPS, estructura de un documento, etiquetas semánticas y formularios.

Prácticas: 1.1 Configuración de entorno local. 1.2 Formulario de registro accesible.

Unidad 2: Estilos Adaptables con CSS3 y Bootstrap 5

Semanas 5 - 10

Modelo de cajas, Flexbox, Grid y componentes responsivos de Bootstrap.

Prácticas: 2.1 Maquetación de sitio estático minimalista. 2.2 Replicación de landing page comercial.

Unidad 3: Lógica e Interactividad Frontend

Semanas 11 - 16

Sintaxis JavaScript, manipulación del DOM y eventos de usuario.

Prácticas: 3.1 Validación de formularios del lado del cliente. 3.2 Proyecto integrador final.
